# Olha Isso, Miga! 🎀

Central web para curadoria, aprovação e publicação de promoções.

## O que funciona nesta versão

- cadastro manual de ofertas;
- filtros;
- validações de preço, vendedor, procedência e disponibilidade;
- bloqueio de aprovação quando faltam validações críticas;
- score explicável;
- gerador de mensagem para WhatsApp;
- copiar mensagem e abrir WhatsApp;
- histórico local;
- backup e importação;
- responsividade para celular e computador.

## Limitações atuais

A pesquisa automática de Amazon, Mercado Livre e Shopee ainda não está conectada dentro do site. As integrações só devem ser consideradas ativas depois de teste real. Os dados desta fase ficam no localStorage do navegador.
